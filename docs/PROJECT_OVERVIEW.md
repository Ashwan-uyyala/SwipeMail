# Project Overview

SwipeMail provides a card-based Gmail experience. Google sign-in requests read-only Gmail access, and the dashboard loads the first 100 mailbox messages into the existing swipe-card interface. Sender, subject, date, labels, preview, and message body come from Gmail.

Swipe gestures currently dismiss cards for the current browser session only. Gmail mutations, background synchronization, and persistent swipe history are not implemented yet.
